# ADR 003: MapLibre and licensed tiles

Planning baseline: 2026-11-07. Proposed design; no participant collection or product implementation has occurred.

Status: proposed baseline, adopted for planning; implementation validation pending.

Decision: MapLibre with a separately licensed tile provider; own bounded GeoJSON.

Alternatives: Google-only maps, default OSM tiles as production/offline service.

Advantages and rationale: Custom atlas layers and portable data.

Disadvantages and risks: Tiles, attribution and offline terms are separate dependencies.

Revisit conditions: Revisit provider on coverage, quotas or budget change.

Evidence checked 2026-11-07: [MapLibre and licensed tiles reference](https://maplibre.org/maplibre-gl-js/docs/). Source describes technology capability, not proof this project is secure or legally compliant.
