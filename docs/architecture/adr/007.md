# ADR 007: Safe aggregates

Planning baseline: 2026-11-07. Proposed design; no participant collection or product implementation has occurred.

Status: proposed baseline, adopted for planning; implementation validation pending.

Decision: Preapproved versioned cohorts and public snapshots with suppression.

Alternatives: Arbitrary query builder, random jitter on raw points.

Advantages and rationale: Reproducible counts and reduced differencing surface.

Disadvantages and risks: Less flexible filters, institutional disclosure review still required.

Revisit conditions: Revisit only with reviewed risk analysis and regression tests.

Evidence checked 2026-11-07: [Safe aggregates reference](https://www.w3.org/TR/WCAG22/). Source describes technology capability, not proof this project is secure or legally compliant.
