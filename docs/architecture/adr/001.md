# ADR 001: Modular monolith and TypeScript

Planning baseline: 2026-11-07. Proposed design; no participant collection or product implementation has occurred.

Status: proposed baseline, adopted for planning; implementation validation pending.

Decision: React/Vite apps and Express API with shared runtime contracts.

Alternatives: Separate microservices or Next.js full stack.

Advantages and rationale: Lower operational load and clear private/public boundaries.

Disadvantages and risks: Several apps need coordinated contract releases; Express requires explicit validation/auth middleware.

Revisit conditions: Revisit if team scale or SSR/search indexing needs justify complexity.

Evidence checked 2026-11-07: [Modular monolith and TypeScript reference](https://expressjs.com/en/advanced/best-practice-security/). Source describes technology capability, not proof this project is secure or legally compliant.
