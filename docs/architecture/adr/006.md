# ADR 006: Identity and server sessions

Planning baseline: 2026-11-07. Proposed design; no participant collection or product implementation has occurred.

Status: proposed baseline, adopted for planning; implementation validation pending.

Decision: Maintained OIDC provider, backend exchange, opaque server sessions.

Alternatives: Custom passwords, browser localStorage JWT.

Advantages and rationale: Delegates credential/MFA operations, revocable scoped sessions.

Disadvantages and risks: Provider setup and offline revocation delay remain.

Revisit conditions: Revisit if institution provides SSO or provider residency unsuitable.

Evidence checked 2026-11-07: [Identity and server sessions reference](https://expressjs.com/en/advanced/best-practice-security/). Source describes technology capability, not proof this project is secure or legally compliant.
