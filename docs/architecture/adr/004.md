# ADR 004: Offline feasibility gate

Planning baseline: 2026-11-07. Proposed design; no participant collection or product implementation has occurred.

Status: proposed baseline, adopted for planning; implementation validation pending.

Decision: Conditional protected PWA; ODK/Kobo fallback with deterministic importer.

Alternatives: Unencrypted IndexedDB, online-only form, native custom app.

Advantages and rationale: Shared web skills and explicit security decision before collection.

Disadvantages and risks: Browser eviction/XSS/key recovery; fallback adapter and Android logistics.

Revisit conditions: Select fallback if real-device security/durability gate fails.

Evidence checked 2026-11-07: [Offline feasibility gate reference](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria). Source describes technology capability, not proof this project is secure or legally compliant.
