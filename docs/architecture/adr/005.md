# ADR 005: Owned panoramas first

Planning baseline: 2026-11-07. Proposed design; no participant collection or product implementation has occurred.

Status: proposed baseline, adopted for planning; implementation validation pending.

Decision: Pannellum with approved own images; optional provider viewer after approval.

Alternatives: Marzipano complex tours, universal Google Street View promise.

Advantages and rationale: Simple self-hosting and content control.

Disadvantages and risks: Capture permissions, WebGL limits and media size.

Revisit conditions: Revisit for multi-scene tours or verified provider coverage.

Evidence checked 2026-11-07: [Owned panoramas first reference](https://pannellum.org/documentation/overview/). Source describes technology capability, not proof this project is secure or legally compliant.
