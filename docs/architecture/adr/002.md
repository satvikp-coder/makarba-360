# ADR 002: PostGIS and publication projection

Planning baseline: 2026-11-07. Proposed design; no participant collection or product implementation has occurred.

Status: proposed baseline, adopted for planning; implementation validation pending.

Decision: PostgreSQL/PostGIS restricted source schema plus explicit published tables.

Alternatives: Document DB, raw-table public views, hosted BaaS direct queries.

Advantages and rationale: Spatial validation and transactional idempotency; separate least-privilege public role.

Disadvantages and risks: Requires migration discipline and verified publication invalidation.

Revisit conditions: Revisit provider only after PostGIS, backup and grant tests.

Evidence checked 2026-11-07: [PostGIS and publication projection reference](https://postgis.net/docs/ST_IsValid.html). Source describes technology capability, not proof this project is secure or legally compliant.
