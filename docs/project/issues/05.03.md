### Summary
Previously enrolled researcher can unlock only within approved offline window.

### Why this is needed
Implement offline session and device lock policy enables the offline fieldwork, synchronisation and media workstream while preserving the researcher-led evidence chain. Without this deliverable: offline revoked account cannot be assumed instantly revoked; reconnect quarantines is not established or verified.

### User story
As a field researcher, I need this reviewed capability so that previously enrolled researcher can unlock only within approved offline window.
