# Operational security checklist

Planning baseline: 2026-11-07. Proposed design; no participant collection or product implementation has occurred.

Before collection: ethics/legal owner approval; least-privilege roles/ownership; strong identity/MFA lead/admin; no public write; secure cookies/CSRF/CSP; secrets scan; upload quarantine; protected device/offline test; retention/withdrawal script; encrypted backup/restore drill. Before public launch: negative raw-data tests, public DTO/EXIF review, cohort differencing tests, independent approval, rights/source audit, no production test data and billing limits. After launch: supported dependencies, account review, backup alerts, publication invalidation/withdrawal drills, incident contacts and handover ownership. These are release gates, not claims checks already passed.
