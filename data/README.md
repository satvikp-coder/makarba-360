# data/

Everything the site shows that isn't code lives here. Edit a file, reload the page in development (`./run.sh`), and the change appears. The production build serves this folder as-is.

| Path | What it holds | Used by |
|---|---|---|
| `forecasts.json` | TimesFM 3.0 forecasts for every indicator. Generated by `./run.sh forecast`; don't edit by hand. | Overview, Outlook, 3D timeline |
| `markets.json` | Optional Yahoo Finance forecasts (personal use). Git-ignored. | Outlook (markets) |
| `content/landmarks.json` | Sourced landmark notes: facts, sources with retrieval dates, why each matters, and photos | Overview, place cards, Library |
| `content/places.json` | One photograph per place slug, with title, credit, licence and Commons link | Place cards, place pages |
| `content/tour.json` | Story-tour stops: title, caption, source, camera position | 3D map tour |
| `content/impacts.json` | What each forecast trend could mean for people: livelihoods, who is affected, and the right to the city | Outlook, AI prompts, 3D highlights |
| `content/scenario.json` | How each visible 3D change in the future scene affects people | Future scene on the map |
| `content/anchors.json` | Named places on the 3D map that highlights (including AI ones) can point to | 3D highlights, AI |
| `geo/osm-landmarks.json` | Real outlines of Sarkhej Roza (mosque and tomb, whole complex) and its tank, from OpenStreetMap | The lake on the 3D map, where the Roza model stands, landmark outlines when selected or toured |
| `geo/osm-roads.json` | The S.G. Highway (NH147), the Sarkhej road (NH8A) and the canal, from OpenStreetMap, clipped to the map | Road and canal lines, highway traffic, the growth corridor |
| `ai/insights.json` | AI highlights and briefings for every forecast year, pre-generated on device (`apps/web/tools/pregen-ai.ts`). Tied to the forecast file it was made from; ignored if the forecasts change. | AI dock, Outlook briefing (instant) |
| `images/landmarks/`, `images/places/` | Photographs (Wikimedia Commons, credited in `docs/project/media-credits.md`) | everywhere photos appear |

## Rules for new content

- **Image paths in JSON** are relative to this folder, for example `"images/places/my-photo.jpg"`.
- **Photos:** use only openly licensed files (Wikimedia Commons: public domain, CC0, CC BY, CC BY-SA). Keep each under 150 KB, and add a row to `docs/project/media-credits.md`.
- **Facts:** paraphrase a cited source and add the retrieval date. Leave out anything you can't check.
- **Impacts and scenario text:** these are interpretations ("could", "may"), not findings.
- **OpenStreetMap data** (`geo/`) is © OpenStreetMap contributors under the ODbL: keep the credit in the map attribution and in each file's `_about`, and record the retrieval date when you refresh it. The Overpass query used is: highway `trunk|primary|secondary|tertiary`, `waterway=canal`, and features named *Sarkhej*/*Roza* or `natural=water`, in the box 22.975–23.005 N, 72.49–72.52 E.
- **AI text** (`ai/`) is generated, not written: regenerate it rather than editing it, and it is always shown as AI-generated.
- **Privacy:** never put participant records, exact interview locations or personal details here. This folder is public.
